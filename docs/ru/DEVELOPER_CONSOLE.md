# Консоль разработчика

> Русская версия. English: [../DEVELOPER_CONSOLE.md](../DEVELOPER_CONSOLE.md).

Нажмите **F8** в игре. Клавиша настраивается — `ConsoleKey` в
`GTA V/Gtamp/client.ini` — это виртуальный код клавиши (119 = F8, 192 = тильда).

```

[11:04:22.118] [INFO]    [CLIENT]   GTAMP client 0.1.0 loaded. Press F8 for the console.
[11:04:22.412] [SUCCESS] [NETWORK]  Connected to 'Los Santos RP' as player 3 (entity #17)
[11:04:22.418] [INFO]    [SERVER]   bob joined the session.
[11:04:31.902] [WARNING] [NETWORK]  Snapshot delay: 120ms

[11:04:33.141] [CRITICAL][NETWORK]  Failed to deserialize entity
```

## Устройство

Консоль намеренно разделена надвое:

- `DeveloperConsole` в `Gtamp.Client.Core` — буфер, фильтры, поиск, таблица
  команд и действия копирования. Никакой отрисовки, никакой GTA V.
- `ConsoleRenderer` в `Gtamp.Client.Shv` — читает модель каждый кадр и рисует её.
  Собственного состояния нет.

Именно из-за этого разделения фильтрация, поиск, история и каждая команда покрыты
юнит-тестами. Это ровно тот вид логики, который тихо гниёт, когда его можно
проверить только стоя в Лос-Сантосе и нажимая F8.

## Цвета

| Роль | Цвет | Когда |
| --- | --- | --- |
| `Critical` | **Ярко-красный на залитой красной строке** | Критическое |
| `Error` | **Красный** | Ошибка |
| `Warning` | **Жёлтый** | Предупреждение |
| `Success` | **Зелёный** | Успех |
| `Debug` | Серый | Отладка |
| `Network` | Светло-синий | Info от сетевой подсистемы |
| `Server` | Фиолетовый | Info от сервера |
| `Client` | Зелёно-серый | Info от клиента |
| `Mod` | Оранжевый | Info от мода или адаптера |
| `Security` | Пурпурный | Info от подсистемы безопасности |

Серьёзность важнее подсистемы: сетевая ошибка красная, а не сетевая-синяя. Когда
вы ищете отказ, вы ищете отказ, а не то, какая подсистема его породила.
Критическое дополнительно получает залитую строку, чтобы его невозможно было
проскроллить.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| F8 | Открыть/закрыть |
| Enter | Выполнить строку |
| Escape | Закрыть |
| Backspace | Удалить символ |
| ↑ / ↓ | История команд |
| Page Up / Page Down | Прокрутка |
| End | Перейти к новейшей строке |

Управление игрой отключено, пока консоль открыта, поэтому нажатия не утекают в
игру.

## Команды

| Команда | Что делает |
| --- | --- |
| `help [command]` | Список команд или объяснение одной |
| `connect [host] [port]` | Подключиться; умолчания из `client.ini` |
| `disconnect` | Покинуть сервер |
| `status` | Сводка по соединению, миру и репликации |
| `players` | Игроки в реплицированном мире |
| `entity <id>` | Полное реплицированное состояние одной сущности |
| `net` | Сетевой отладчик: пинг, потери, полоса, снапшоты, перепосылки |
| `mods` | Обнаруженные моды и статус адаптеров |
| `diagnostics` | Проверить установку и сессию |
| `report <text>` | Построить баг-репорт и скопировать в буфер обмена |
| `say <text>` | Отправить сообщение в чат |
| `filter <name>` | `all`, `info`, `debug`, `warning`, `error`, `critical`, `network`, `server`, `client`, `mod`, `security` |
| `search [text]` | Фильтровать строки по тексту; без аргумента — сброс |
| `copy [message\|stack\|full] [errorId]` | Скопировать последнюю проблему или указанную по id |
| `clear` | Очистить буфер |
| `dev [on\|off]` | Переключить режим разработчика |

Только для разработчика (скрыты и отклоняются до `dev on`):

| Команда | Что делает |
| --- | --- |
| `resync` | Выбросить реплицированный мир и запросить полный снапшот |
| `schema` | Список зарегистрированных типов сущностей и их реплицируемых полей |
| `reload config` | Перезагрузить конфигурацию клиента |

## Поиск

Ищет по сообщению, деталям, тегу, уровню, категории и метке времени.

Два уточнения, важные на практике:

- **Запрос из одних цифр — это точный поиск по id ошибки.** Поиск подстроки по id
  попадал бы и в каждую метку времени, содержащую эти цифры, из-за чего
  `search 152` бесполезен для поиска ошибки 152.
- **Метка времени ищется только когда в запросе есть двоеточие.** Иначе
  `search 1` совпадает с каждой строкой, записанной в 11-м часу, и топит
  результат.

Фильтр и поиск сочетаются: `filter error`, затем `search entity 7` даст вам
ошибки про сущность 7 и ничего больше.

## Копирование

Любую проблемную строку можно скопировать в четырёх формах (раздел 41
мастер-промпта):

- `copy message` — только сообщение
- `copy stack` — трассировка стека
- `copy full` — отформатированная строка плюс её детали
- `report <text>` — полный баг-репорт

Копирование целится в самую свежую **проблему** (предупреждение и выше), а не в
самую свежую строку: к моменту, когда вы до неё тянетесь, ошибка обычно уже уехала
вверх за рутинной болтовнёй. Передайте id ошибки, чтобы указать конкретную.

Запись в буфер обмена выполняется в короткоживущем STA-потоке, потому что буфер
обмена Windows требует такого потока, а поток скриптов ScriptHookVDotNet им не
является.

## Баг-репорты

`/report Vehicle #152 disappears after reconnect` порождает формат из раздела 43
мастер-промпта и копирует его в буфер обмена, готовым для вставки в трекер или в
Claude Code:

```
=== MULTIPLAYER BUG REPORT ===

BUG_ID: 8F2A1C4D9E03
DATE: 2026-08-31 11:04:33Z
SEVERITY: MEDIUM

SUBSYSTEM: Entity
GTA V VERSION: v1_0_3095_0
MULTIPLAYER VERSION: 0.1.0
RPH VERSION: 1.124.0.0
LSPDFR VERSION: 0.4.9
SCRIPTHOOKV: present

MODS:
  scripthookv 1.0.3095.0
  ...

DESCRIPTION / STEPS TO REPRODUCE / EXPECTED / ACTUAL
PLAYER:   имя, идентификаторы, позиция, здоровье, интерьер
ENTITY:   число реплицированных, удалённые педы, первые 25 сущностей
NETWORK:  состояние, сервер, пинг, потери, пакеты, байты, перепосылки, снапшоты, ресинхронизации
STACK TRACE
RECENT EVENTS:  последние 10 предупреждений и ошибок

```

Никуда ничего не отправляется. Отчёт попадает в буфер обмена и в файл лога, а
игрок сам решает, что с ним делать.

## Диагностика

`/diagnostics` проверяет установку и живую сессию:

```
=== DIAGNOSTICS ===
✓ GTA V                v1_0_3095_0
✓ Multiplayer          client 0.1.0
✓ ScriptHookV          installed
✓ ScriptHookVDotNet    3.6.0
✓ RAGE Plugin Hook     1.124.0.0
⚠ LSPDFR               not installed (optional)
✓ Mods                 27 detected (4 ASI, 12 scripts, 0 LSPDFR plugins)
✓ Adapters             1 active, 1 inactive
✓ Server               Los Santos RP at 203.0.113.9:27015
✓ Network              38 ms, 0.4% loss
✓ Entity schema        0xB0AC13FC
✓ Game directory       D:\Games\Grand Theft Auto V
=== END DIAGNOSTICS ===
```

Отсутствующий **опциональный** компонент отмечается `⚠`, а не `✗`. Каждый
опциональный компонент в этом фреймворке действительно опционален, и пометка его
отсутствия как отказа приучила бы людей игнорировать те отказы, которые важны.

## Серверная консоль

У сервера тот же набор команд на stdin: `status`, `players`, `entities`,
`entity <id>`, `net`, `kick`, `say`, `time`, `weather`, `save`, `diagnostics`,
`stop`. См. [../../DEV_COMMANDS.ru.md](../../DEV_COMMANDS.ru.md).

Перенаправленный stdin тоже читается, поэтому и `echo stop | Gtamp.Server`, и
консоль контейнера работают.
