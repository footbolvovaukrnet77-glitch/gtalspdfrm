# gtalspdfrm

Бот для автоматической игры в браузерную игру-бегалку на компьютерном зрении (OpenCV + MSS + PyAutoGUI).

Проект: [`game_bot/`](game_bot/) — инструкция по установке, калибровке и настройке в [game_bot/README.md](game_bot/README.md).

```bash
cd game_bot
pip install -r requirements.txt
python main.py
```
