# Game Bot — бот для браузерной игры-бегалки (компьютерное зрение, без нейросетей)

Бот смотрит на игру через захват экрана, находит персонажа и препятствия
по цвету/форме, прогнозирует их сближение и управляет персонажем клавишами
**A / D / SPACE**.

Нейросети не используются — только OpenCV, HSV-маски, контуры и трекинг.

---

## 1. Установка Python

**Windows**
1. Скачайте Python 3.10+ с https://www.python.org/downloads/
2. При установке обязательно отметьте **«Add python.exe to PATH»**.
3. Проверьте: откройте «Командную строку» и выполните
   ```
   python --version
   ```

**Linux (Ubuntu/Debian)**
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv python3-tk
```

**macOS**
```bash
brew install python
```
Для macOS дополнительно разрешите приложению «Терминал» доступ в
*Системные настройки → Конфиденциальность и безопасность → Универсальный доступ*
и *Запись экрана*, иначе бот не сможет нажимать клавиши и снимать экран.

## 2. Установка зависимостей

```bash
cd game_bot
python -m venv venv

# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

Если что-то не установилось, ставьте по одному пакету:

```bash
pip install numpy
pip install opencv-python
pip install mss
pip install pyautogui
pip install pynput
pip install Pillow
```

Linux дополнительно (для pyautogui/pynput нужен X11):

```bash
sudo apt install python3-xlib scrot python3-tk
```

Проверка, что всё встало правильно:

```bash
python main.py --selftest
```

Ожидаемый результат — `Пройдено: 17/17`.

## 3. Запуск

```bash
python main.py
```

Появится меню:

```
  [1] Запустить бота
  [2] Калибровка
  [3] Настройки
  [4] Выход
```

Быстрые запуски без меню:

```bash
python main.py --run           # сразу запустить бота
python main.py --calibrate     # сразу калибровка
python main.py --selftest      # самопроверка проекта
python main.py --run --dry-run # бот работает, но НЕ нажимает клавиши (безопасная проверка)
python main.py --run --no-debug --fps 30
```

После запуска бот даёт 5 секунд на переключение в браузер:

```
Бот запустится через 5 секунд. Переключитесь на окно игры.
```

Время меняется параметром `START_DELAY`.

## 4. Настройка области игры

Бот захватывает **только область игры**, а не весь монитор — это и быстрее,
и точнее.

**Способ 1 — мышью (рекомендуется)**
1. `python main.py` → `[2] Калибровка` → `[1] Выбрать область игры мышью`
2. Переключитесь на браузер с игрой — через 4 секунды будет сделан скриншот.
3. Выделите мышью прямоугольник игрового поля, нажмите **ENTER**.
4. Область сохранится в `config.json`.

**Способ 2 — вручную** в `config.py` (или в `config.json`):

```python
GAME_REGION = {
    "left": 100,    # X левого верхнего угла игры на экране
    "top": 100,     # Y левого верхнего угла
    "width": 800,   # ширина области
    "height": 600,  # высота области
}
```

Выделяйте только игровое поле, без адресной строки браузера и вкладок.

## 5. Калибровка цветов

`python main.py` → `[2] Калибровка` → `[2] Калибровать цвета`

Откроется живое окно захвата. Управление:

| Клавиша | Действие |
|---------|----------|
| **ЛКМ** | взять образец цвета под курсором |
| **P**   | режим ИГРОК |
| **O**   | режим ПРЕПЯТСТВИЕ |
| **T**   | режим ДОРОЖКА (зелёные линии) |
| **C**   | очистить образцы текущего режима |
| **+ / −** | увеличить/уменьшить допуск по оттенку |
| **M**   | показать/скрыть маску |
| **S**   | сохранить в `config.json` |
| **Q / ESC** | выход |

### Как откалибровать игрока
1. Нажмите **P**.
2. Кликните 3–6 раз по разным частям робота (корпус, голова, светлые детали).
3. В окне `Calibration: mask` робот должен светиться белым, фон — чёрным.
4. Если засвечивается лишнее — нажмите **C** и кликайте точнее либо уменьшите
   допуск клавишей **−**.
5. **S** — сохранить.

### Как откалибровать препятствия
1. Нажмите **O**.
2. Кликните по розовой планке и по голубым стойкам (можно смешивать —
   диапазон расширится). Если цвета сильно разные, лучше основной цвет задать
   кликами, а второй добавить вручную в `OBSTACLE_HSV_EXTRA_RANGES`.
3. Проверьте маску: должны светиться только препятствия.
4. **S** — сохранить.

### Как откалибровать дорожку
Нажмите **T** и кликните по зелёным линиям трассы. Эти цвета будут
**вычитаться** из маски препятствий (`USE_TRACK_MASK = True`), чтобы бот не
принимал разметку за препятствие.

### Проверка
`[2] Калибровка` → `[3] Предпросмотр детекции`: игрок обводится зелёным,
препятствия — красным. Так проще всего убедиться, что настройки верные.

## 6. Запуск браузера и игры

1. Откройте игру в браузере.
2. Желательно окно без масштабирования (100%) и без изменения размера
   во время работы бота — иначе область захвата «уедет».
3. Кликните мышью по игровому полю, чтобы фокус клавиатуры был в игре
   (иначе нажатия уйдут в браузер, а не в игру).
4. Запустите `python main.py` → `[1] Запустить бота` и за 5 секунд
   переключитесь обратно в игру.

Первый запуск рекомендуется делать с `--dry-run` — бот всё видит и печатает
решения, но не нажимает клавиши.

## 7. Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| **F6**  | старт / пауза |
| **F7**  | полностью остановить бота |
| **F8**  | включить/выключить DEBUG-окно |
| **ESC** | аварийная остановка (все клавиши немедленно отпускаются) |
| **R**   | перезапуск игры на экране GAME OVER |

Глобальные горячие клавиши работают через `pynput`. Если он не установлен,
управляйте из окна DEBUG (оно должно быть в фокусе):
**P** — пауза, **X** — стоп, **D** — debug, **ESC** — выход.

> На Linux глобальные хоткеи требуют X11-сессии; на Wayland может
> потребоваться запуск в X11-режиме.

## 8. DEBUG-окно

`DEBUG_MODE = True` (или **F8**) открывает окно OpenCV, где показаны:

* зелёная рамка вокруг игрока и вертикальная линия его центра;
* красные рамки препятствий (жёлтая — ближайшая угроза) и стрелки прогноза;
* жёлтая стрелка — предполагаемая траектория (куда бот ведёт персонажа);
* зелёные полупрозрачные зоны — свободное место слева/справа;
* серая линия — центральная траектория и коридор `LANE_TOLERANCE`;
* текст:

```
PLAYER: x=350 y=620 w=44
OBSTACLE: x=450 y=400 w=160
DISTANCE: 220
TTI: 0.42s  SPEED: 310px/s
FREE L/R: 244 / 183
ACTION: MOVE LEFT
STATE: AVOID_LEFT
FPS: 30
```

`DEBUG_SHOW_MASKS = True` дополнительно показывает бинарные маски — это
самый быстрый способ понять, почему бот что-то «не видит».

## 9. Структура проекта

```
game_bot/
├── main.py                  # меню, главный цикл, горячие клавиши, FPS
├── config.py                # ВСЕ параметры (HSV, дистанции, клавиши, FPS)
├── config.json              # сохранённые настройки (перекрывают config.py)
├── screen_capture.py        # быстрый захват области экрана (MSS / PyAutoGUI)
├── player_detector.py       # detect_player(frame)
├── obstacle_detector.py     # detect_obstacles(frame)
├── vision_utils.py          # HSV-маски, контуры, склейка боксов, DetectedObject
├── tracker.py               # трекинг препятствий, скорость, прогноз, дистанции
├── decision_engine.py       # логика уклонения и прыжка
├── keyboard_controller.py   # безопасное управление клавишами
├── hotkeys.py               # F6 / F7 / F8 / ESC
├── game_state.py            # конечный автомат + детектор GAME OVER
├── debug_view.py            # отладочное окно OpenCV
├── calibration.py           # выбор области игры и подбор HSV
├── selftest.py              # самопроверка (17 тестов)
├── requirements.txt
└── README.md
```

### Как работает конечный автомат

```
SEARCHING
   ↓ найдено препятствие в траектории
проверка свободного места слева/справа
   ↓
AVOID_LEFT / AVOID_RIGHT      (или JUMPING, если обойти нельзя)
   ↓ препятствие прошло игрока
RECOVERING
   ↓
MOVING_CENTER → SEARCHING
```

Состояния: `SEARCHING`, `MOVING_CENTER`, `AVOID_LEFT`, `AVOID_RIGHT`,
`JUMPING`, `RECOVERING`, `DEAD`, `PAUSED`.

## 10. Настройка чувствительности

Все параметры — в `config.py` (и сохраняются в `config.json`).

### Бот реагирует слишком поздно / врезается

| Параметр | Что сделать |
|----------|-------------|
| `REACTION_DISTANCE` | **увеличить** (300 → 380…450) — бот начнёт манёвр раньше |
| `JUMP_DISTANCE` | увеличить (190 → 240) — прыжок раньше |
| `JUMP_TIME_AHEAD` | увеличить (0.35 → 0.5) — прыжок за больше времени до удара |
| `PREDICTION_TIME` | увеличить (0.35 → 0.5) — сильнее учитывать прогноз |
| `TARGET_FPS` | увеличить (30 → 45) — быстрее реакция, если хватает CPU |
| `PROCESS_SCALE` | уменьшить (1.0 → 0.6) — быстрее обработка кадра |
| `MOVE_MAX_HOLD` | увеличить, если персонаж не успевает доехать до края |

### Бот слишком часто прыгает

| Параметр | Что сделать |
|----------|-------------|
| `JUMP_COOLDOWN` | **увеличить** (0.55 → 0.9…1.2) — реже прыжки |
| `JUMP_SAME_OBSTACLE_COOLDOWN` | увеличить (1.2 → 2.0) — один прыжок на препятствие |
| `JUMP_DISTANCE` | уменьшить (190 → 150) — прыгать только вблизи |
| `JUMPABLE_HEIGHT_RATIO` | уменьшить (0.16 → 0.10) — считать «перепрыгиваемыми» только низкие препятствия |
| `UNAVOIDABLE_WIDTH_RATIO` | увеличить (0.55 → 0.7) — чаще пытаться обойти сбоку, а не прыгать |
| `OBSTACLE_MARGIN` | уменьшить (18 → 10) — бот решит, что сбоку места хватает |

### Бот дёргается влево-вправо

| Параметр | Что сделать |
|----------|-------------|
| `LANE_TOLERANCE` | увеличить (25 → 45) — меньше мелких доворотов к центру |
| `TRACK_SPEED_SMOOTHING` | увеличить (0.6 → 0.8) — плавнее оценка скорости |
| `MOVE_MIN_HOLD` | увеличить — движение более «крупными» шагами |

### Бот путает препятствие с другими объектами

| Параметр | Что сделать |
|----------|-------------|
| `OBSTACLE_HSV_LOWER/UPPER` | сузить диапазон (перекалибровать, меньший допуск **−** в калибровке) |
| `OBSTACLE_HSV_EXTRA_RANGES` | убрать лишние диапазоны или задать их точнее |
| `OBSTACLE_MIN_AREA_RATIO` | увеличить (0.0003 → 0.001) — отсечь мелкий мусор |
| `OBSTACLE_MIN_WIDTH_RATIO` / `OBSTACLE_MIN_HEIGHT_RATIO` | увеличить — отсечь тонкие блики |
| `USE_TRACK_MASK` | `True` + откалибровать `TRACK_HSV_*` — исключить зелёную дорожку |
| `OBSTACLE_MERGE_DISTANCE_RATIO` | увеличить, если одно препятствие распадается на куски; уменьшить, если разные препятствия слипаются |
| `MORPH_KERNEL` | увеличить (5 → 7) — сильнее подавление шума |
| `OBSTACLE_SEARCH_BOTTOM_RATIO` | уменьшить (0.98 → 0.85) — игнорировать зону у самого низа |

### Бот не видит игрока

| Параметр | Что сделать |
|----------|-------------|
| `PLAYER_HSV_LOWER/UPPER` | перекалибровать (режим **P**) |
| `PLAYER_SEARCH_TOP_RATIO` | уменьшить (0.55 → 0.4), если персонаж выше середины |
| `PLAYER_MIN_AREA_RATIO` | уменьшить, если робот маленький |
| `PLAYER_MAX_ASPECT` | увеличить, если персонаж вытянутый |
| `PLAYER_MEMORY_FRAMES` | увеличить — дольше держать последнее известное положение |

## 12. Защита от залипания клавиш

Это критичная часть — «зажатая» клавиша после падения программы мешает
работать за компьютером. В боте четыре независимых уровня защиты:

1. `try/finally` в главном цикле — `release_all()` при любом исходе;
2. `atexit` — при штатном завершении процесса;
3. обработчики `SIGINT`/`SIGTERM` — при Ctrl+C и `kill`;
4. `KeyboardController.update()` — принудительно отпускает клавишу,
   удерживаемую дольше `MOVE_MAX_HOLD`.

Плюс **ESC** — мгновенная аварийная остановка.

Если клавиша всё же осталась зажатой (например, при жёстком завершении
процесса), просто нажмите и отпустите её вручную или выполните:

```bash
python -c "import pyautogui; [pyautogui.keyUp(k) for k in ('a','d','w','s','space','left','right','up','down')]"
```

## 13. GAME OVER

Бот считает игру оконченной, если:

* игрок не находится `GAME_OVER_LOST_FRAMES` кадров подряд, **или**
* картинка перестала меняться `GAME_OVER_STATIC_FRAMES` кадров, **или**
* экран стал почти чёрным (`GAME_OVER_DARK_V_MEAN`).

В этот момент состояние переходит в `DEAD`, все клавиши отпускаются и в
консоли/окне появляется:

```
=== GAME OVER ===
  [R]   — начать заново
  [ESC] — остановить бота
```

`R` отправляет в игру клавишу `RESTART_KEY` (по умолчанию `r`) и сбрасывает
детекторы. При `AUTO_RESTART = True` перезапуск произойдёт сам.

Если бот ложно определяет GAME OVER — увеличьте `GAME_OVER_LOST_FRAMES`
и `GAME_OVER_STATIC_FRAMES`.

## 14. Устранение проблем

| Проблема | Причина и решение |
|----------|-------------------|
| `ModuleNotFoundError: No module named 'cv2'` | `pip install opencv-python` |
| `ModuleNotFoundError: No module named 'mss'` | `pip install mss` |
| `Нет бэкенда захвата экрана` | `pip install mss` или `pip install pyautogui pillow` |
| `Cannot connect to display` (Linux/сервер) | нужен графический сеанс X11; на headless-машине бот работать не может |
| Бот видит игру, но персонаж не двигается | фокус клавиатуры не в игре — кликните по игровому полю; проверьте `DRY_RUN = False`; попробуйте `USE_ARROW_KEYS = True` |
| Нажатия не доходят до игры (Windows) | запустите терминал **от имени администратора** — игры/браузеры в защищённом режиме не принимают ввод от обычного процесса |
| macOS: ничего не нажимается | дайте терминалу права «Универсальный доступ» и «Запись экрана» |
| Игрок не найден («PLAYER: NOT FOUND») | перекалибруйте `PLAYER_HSV_*`, уменьшите `PLAYER_SEARCH_TOP_RATIO` |
| Красными обводится вся дорожка | включите `USE_TRACK_MASK`, откалибруйте `TRACK_HSV_*`, сузьте `OBSTACLE_HSV_*` |
| Низкий FPS | `PROCESS_SCALE = 0.6`, `DEBUG_MODE = False`, уменьшите `GAME_REGION`, `DEBUG_SHOW_MASKS = False` |
| Горячие клавиши не работают | `pip install pynput`; на Linux — X11-сессия; либо управляйте из DEBUG-окна (P/X/D/ESC) |
| Область захвата «съехала» | окно браузера сдвинули/изменили масштаб — перекалибруйте область |
| Бот постоянно жмёт SPACE | см. раздел 10 «Бот слишком часто прыгает» |
| Клавиша залипла | нажмите **ESC**; см. раздел 12 |

## 15. Самопроверка

```bash
python main.py --selftest
```

Проверяются: импорты всех модулей, чтение/запись `config.json`, детекция
игрока и препятствий на синтетических кадрах, трекинг и оценка скорости,
логика уклонения и прыжка, конечный автомат, `KeyboardController`
(взаимоисключение A/D, кулдаун прыжка, освобождение клавиш при исключении),
детектор GAME OVER, отрисовка debug-кадра и разбор аргументов `main.py`.

## 16. Ограничения

* Бот рассчитан на цветовую детекцию: при смене палитры игры нужна
  повторная калибровка.
* Нужен видимый экран — на headless-сервере захват невозможен.
* Скорость и «физика» прыжка у каждой игры своя: подберите
  `JUMP_TIME_AHEAD`, `JUMP_DISTANCE` и `JUMP_COOLDOWN` под свою игру.
* Используйте бота только там, где это допустимо правилами игры.
